# RTX 5090 · Qwen3-Omni Thinker / Thinking

| 方案 | 卡型 / 并行 | 已记录完整输出吞吐 | 实现 |
|---|---|---:|---|
| [异步调度 + FP8 GEMM + FP8 KV](async-fp8-gemm-fp8-kv-tp1-c4/readme.md) | RTX 5090 32 GiB × 1，TP1，客户端 C4 | **3.024 条/分钟** | vLLM / vLLM-Omni 0.30.0 |

3.024 为 2026-10-20 两轮完整测试的合并结果，15 个冻结样本 × 2 轮，共 30 次正式请求；包含 Thinking。相同配置另一次两轮复测为 2.815 条/分钟，不能保证每次达到 3.024。

该方案实际包括 **FP8 E4M3 KV Cache**，不是 BF16 KV。GEMM 量化范围是 48 个 QKV 和 48 个 O 线性层；MoE 专家保持实验权重原有 NVFP4，router、lm_head 与编码器保持原精度。

每个方案目录包含自己的启动方式、测试方法、实际版本、性能指标、配置、代码与报告。需要自备有权限使用的模型和数据，仓库不分发权重、媒体、业务 prompt 或凭证。

3. 优化项与实际配置

项目配置与作用范围
选择性 FP8 GEMM48 QKV + 48 O，共 96 层；E4M3 W8A8；静态 tensorwise 权重 scale、动态激活量化，BF16 输出；实际 CutlassFP8ScaledMMLinearKernel。
保持的原精度48 层 MoE 专家保持模型原有 NVFP4 CUTLASS；router、lm_head、视觉与音频编码器不纳入该 FP8 替换。
异步调度async_scheduling=true；实际 OmniARAsyncScheduler。与 async_chunk 音频流式功能不同，本方案 async_chunk=false。
CUDA Graph 与编译enforce_eager=false，mode=3，FULL_AND_PIECEWISE，capture sizes=[1,2,4]，custom_ops=[+rotary_embedding]。
长输入 prefillenable_chunked_prefill=true，max_num_batched_tokens=4096，上下文 65536。
并发容量TP1，max_num_seqs=4，客户端并发 4。
FP8 KV48 层 E4M3 KV，固定 6,710,886,400 bytes（6.25 GiB），采用随包保存的原校准 K/V scales。
注意力路径FlashInfer / XQA decode，Q 保持 BF16；disable_flashinfer_q_quantization=true。
缓存边界prefix caching 关闭，多模态处理器缓存 0；每个请求使用独立媒体缓存命名空间。

以上是组合配置说明。未在本目录做每一项独立的同卡消融，不能将组合吞吐归因给某一项，也不能叠加各项理论收益。

4. 性能输入与测试方法

15 个冻结样本分为 3 组，每组 5 条；每条为约 12–15 秒原视频及同步音轨、目录内全部 3–5 张参考图、完整 system prompt 与预先冻结的 shot_plan/runtime context。视频以 2 fps 采样，use_audio_in_video=true。每轮输入 tokens 合计 419,460，两轮 838,920。公开证据用匿名 sample 编号、哈希和数值保留逐条可核查性；原媒体、业务 prompt 和原始 Caption 不在公开仓库中。

每轮完整预热 1 条后，以 C4 测试 15 条，两轮共 30 次正式请求。temperature=0、seed=0、enable_thinking=true、max_tokens=16384。预热与启动/编译排除在正式吞吐之外。客户端进行输入文件 SHA256、预检 token 数、Thinking、JSON 结构、流完整性、GPU 归属与 API 请求计数检查；错误或截断不会列为完整输出。

  • 条/分钟 = 完整正式请求数 / 正式批次 wall × 60。两轮合并使用总数 / 总 wall。
  • 输出 token/s/卡 = 全部 completion tokens / 总 wall / GPU 数，包含 Thinking 与 Caption，不含输入 tokens。
  • TTFT：HTTP 发出到首个文本 token，包含 Thinking。
  • TPOT：(请求 E2E − TTFT) / (completion tokens − 1)，包含首 token 后的调度、抢占重算和流结束影响。
  • 请求 E2E：HTTP 开始到最终 SSE 完成，包括服务端排队、prefill、Thinking、Caption。样本 E2E 另含客户端媒体准备；批次 wall 再含客户端排队。
  • P50 从全部 30 个请求重算；两轮均要求 GPU 选卡无其他服务进程、无额外生成请求。

6. 质量与复现边界

协议完整和 JSON 结构有效不等于视频语义正确。本方案没有已经验收的人工 Caption 精度结论，不宣称精度无损。实验使用非官方 Thinking-heretic-NVFP4 衍生权重，不能当作官方 BF16 Thinking 模型的等价精度结果。

复现 3.024 需要同一冻结媒体、完整 system prompt、shot plan、模型指纹及相容环境；换数据会改变输入、输出长度和性能。新增启动/测试封装做了路径参数化整理，发布过程中未重新跑 GPU 测试；原始测量来自保存的历史运行。核心 worker 和流式请求/计时代码保留原实现，封装适配记录在 evidence/client-provenance.json。

公开仓库没有机器 IP、登录账号、私有路径、GPU UUID、PID、API key、SSH key、GitHub token、私有镜像地址或原始业务数据。此 HTML 完全独立，无外部脚本、字体或其他 HTML 依赖。
